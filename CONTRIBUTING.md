# Contributing to GoldenEye

We welcome improvements that enhance security education.

1. **Fork** the repository and create a feature branch.
2. **Keep ethical** – no changes encouraging illegal activity.
3. **Test** in an isolated VM lab.
4. **Submit a pull request** with a clear description.

Areas for contribution:
- Additional attack vectors (DNS amplification, NTP reflection)
- Machine learning for anomaly detection
- More detailed reporting (PDF/HTML)
- Windows version (PowerShell)

By contributing, you agree your code is licensed under MIT.
